Libbitcoin is developed in the open on [GitHub](https://github.com/libbitcoin).
Each library is its own repository, and every change is a pull request
against `master`, built and tested by CI on Linux, macOS and Windows before
review. See the [Overview](index) for the stack, and
[Building](../building/index) to build it. The libraries are licensed
under the [AGPL](https://www.gnu.org/licenses/agpl-3.0.en.html) with a
lesser clause, and contributions are accepted under the same license.

Report bugs and propose features as issues on the relevant repository. A
pull request follows the [Style guide](style) and carries tests for what it
changes, per [Test practices](testing).

Discussion takes place in the Libbitcoin Slack, which anyone can join, and
is archived in the [Slack mirror](../slack/index.html). Open meetings are
held as a huddle in its #general channel, commonly on Wednesdays at noon
New York time.
